# Claude Instructions

This repository contains the Operations Maturity System.

The project is designed to become a modular web application for understanding, diagnosing, designing, and improving business operations.

## Core rules

- Preserve the existing repository structure.
- Do not collapse the project into a single file.
- Keep content, styling, logic, and pages separated.
- Make incremental changes instead of rebuilding the entire project.
- Keep all paths compatible with GitHub Pages.
- Reuse existing patterns before creating new ones.
- Do not delete files unless explicitly instructed.

## Product philosophy

Every business has an operating system. Most just haven't designed it intentionally.

Stop fixing symptoms. Start designing systems.
